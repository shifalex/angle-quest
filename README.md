# Angle Quest — משימת הזוויות

אב־טיפוס למשחק למידה קצר, מותאם למחשב ולטלפון. התלמיד בוחר כלי מתוך משפחת חוקים, לוחץ בשרטוט כדי להניח אותו כ־`AUGMENTED`, ואז גורר, מסובב ומכוון אותו אל המקום החסר.

## הפעלה

פתחו את `index.html` בדפדפן. אין צורך בהתקנה, שרת או חיבור לרשת.

## מה כלול בדמו

- בשלב המתקדם אפשר לכוון את מפתח הזווית מחדה לקהה. שלב עתידי יכול להפעיל `lockAngleType` ולשמור על סוג הזווית.
- שתי משפחות חוקים: שוות (קודקודיות, מתחלפות, מתאימות) ו־180° (צמודות, משולש).
- ארבעה שלבי מתחילים ממשפחת „פרימיטיבים”: בוחרים חדה, ישרה, שטוחה או קהה ואז גוררים ומניחים אותה על זווית המטרה. סוג הזווית נעול בשלב זה.
- לאחריהם חמישה שלבים מתקדמים; הפרימיטיבים נשארים גלויים אך נעולים ומשפחות שוות ו־180° נפתחות.
- שלבי ה־PRO מופיעים בסדר אקראי, השרטוט כולו עשוי להיות מסובב, ובחלק מהמשימות נוספים קווי הסחה אקראיים.
- פתרון מעניק 100 XP, ובחירת הכלי הנכון כבר בניסיון הראשון מעניקה עוד 50 XP.
- בחירת כלי מציגה אותו מיד במיקום ההתחלתי ומקריאה בעברית את שמו, כל עוד הצליל מופעל.
- ההקראה ממתינה לטעינת קולות המערכת, מעדיפה קול `he-IL`, וכפתור 🔊 מקריא „הקול פועל” לצורך בדיקה.
- לחיצה נוספת על שם הכלי הפעיל מעלימה אותו ומבטלת את הבחירה; לחיצה חוזרת מציגה אותו מחדש.
- צורת ה־AUGMENTED מייצגת את החוק: X לקודקודיות, Z למתחלפות ו־F למתאימות.
- ה־Z מונחת כברירת מחדל כשני קווים אופקיים ואלכסון היוצר זוויות חדות; ה־F מונחת עם קו אנכי, זרועות אופקיות וזוויות ישרות. סדר שמות הכלים מתערבב מחדש בכל שלב.
- משימות מתחלפות ומתאימות מגרילות בכל פעם זווית בין 40° ל־140°, ולכן עשויות להיות חדות, ישרות או קהות.
- בכלי השוויון מודגשות תמיד שתי הזוויות השוות: הזוג הקודקודי ב־X, המתחלף ב־Z והמתאים ב־F.
- גרירה מזיזה את הצורה, הידית העליונה מסובבת, ידיות כחולות משנות את מפתח הזווית וידיות כתומות משנות את נקודות ה־Z וה־F.
- אפשר לזרוק כלי שהונח ולבחור או להניח כלי מחדש.
- מראה זמינה גם בכפתור וגם בדאבל־קליק או דאבל־טאפ על גוף הכלי; כל ידיות המגע נשארות פעילות גם בצד ההפוך.
- הפליפ מתבצע שמאל־ימין סביב מרכז הצורה החזותי, כך שהאות נשארת באותו שטח ולא קופצת סביב קודקוד קצה.
- הפליפ מונפש דרך השטחה למרכז ופתיחה בצד ההפוך, וניתן להפעילו בדאבל־קליק או דאבל־טאפ בכל מקום בשטח השרטוט.
- ל־Z יש ידית גובה ייעודית על הקו העליון וידית אורך בקצה הקו התחתון.
- לחיצה בקנבס מניחה את הכלי בפעם הראשונה. לאחר מכן רק גרירת גוף הכלי מזיזה אותו; לחיצה נוספת בקנבס אינה משנה דבר.
- אזור הגרירה הוא כל המלבן השקוף שסוגר את קווי הכלי, ולא רק הקווים עצמם.
- ידיות הגובה מאפשרות להגביה את ה־Z וה־F עד כ־240px, בהתאם לשטח השרטוט.
- ידיות הגובה והאורך פועלות לפי השינוי מתחילת הגרירה כדי למנוע קפיצה. כפתורי הזווית פועלים בצעדי 5° וגרירת מגע מתקבלת בטווח של 5° מהיעד.
- למשולש יש ידית „גודל” שמגדילה או מקטינה את כל הצורה באופן אחיד.
- משוב נפרד לבחירת החוק, בחירת הזווית, המיקום והסיבוב.
- כותרת המשימה והרמז אינם חושפים את החוק, ואזורי הטקסט שמורים בגובה קבוע כדי למנוע קפיצות בפריסה.
- מבנה שלבים מבוסס נתונים ב־`app.js`, כדי שאפשר יהיה להוסיף בהמשך מצולעים, חוקי 0 ו־1 ופיתגורס.
